## “互联网漂流了这么久，也该有一个自己的小角落了。”
于是，我开始了第一次真正意义上的“现代开发”。

而结果就是：

被 Git、Cloudflare、PowerShell、代理、终端等等名词袭脸！

---

# 一切的开始：Fork

教程第一步就是：

> “请先 Fork 仓库”

当时的我：

“Fork 是什么？”

后来才明白：

Fork 本质上就是：

> “把别人的 GitHub 项目复制到自己账号下面”

相当于：

```text
作者仓库
↓
复制一份到自己账号
↓
变成自己的项目
```

也是从这里开始，我第一次真正开始接触 GitHub 工作流。

---

# 然后我卡在了 git clone

教程让我输入：

```bash
git clone xxxxx
```

但问题来了。

我甚至不知道：

> “这玩意到底输入在哪？”

最后才知道：

原来这些命令需要在：

- Git Bash
- 或者 VS Code 的 Terminal

里面输入。。。

第一次打开黑框框的时候，真的有一种：

> “我要开始当码农了吗？”

的感觉呢。

---

# Git 仓库消失事件

因为 GitHub 网络问题，我最后选择了：

```text
Download ZIP
```

结果后面教程又让我：

```bash
git add .
git commit
```

然后：

```text
fatal: not a git repository
```

我当场懵掉。

后来才知道：

ZIP 下载不会包含：

```text
.git
```

也就是说：

虽然文件看起来一样。

但它已经不是 Git 仓库了。

于是我又重新：

```bash
git init
```

重新绑定远程仓库。。

---

# Cloudflare 部署：最后一关

终于，本地博客跑起来了。

我兴冲冲开始部署 Cloudflare。

然后：

炸了。

日志里一大片英文。

唉，就像是高中学信技，前面学单纯理解代码都还好，但是后期开始接触网络相关的就感觉不懂了。。。

后来慢慢定位问题，发现问题是：

Cloudflare Workers 和静态博客配置冲突。

然后。。。我就不懂了，ChapGpt的名词我一个看不懂。

最后发现是一个配置文件放在根目录的上一级目录了，哈哈😅

---

# 第一次真正理解“本地开发”

以前总觉得：

网站是个很遥远的东西。

但这次我第一次理解：

```text
本地修改
↓
git push
↓
Cloudflare 自动部署
↓
网站更新
```

整个现代前端开发流程。



---

# Markdown 

博客文章居然是 Markdown 写的，程序员都这么厉害的吗-=-

还发现 Markdown 本质上就是：

> “会自动变成网页的文本”

这一点真的特别浪漫。

写下：

```markdown
# Hello World
```

它就会变成真正的网站标题。
