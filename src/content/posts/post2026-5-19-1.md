## 闲来无事让ChatGpt生成了一个简单的生日贺卡。
- 真的非常的简单的那种，纯静态，三页，只使用简单的html、css和JaveScript的那种。

- 不过透过这个项目还是稍微学到一点点东西的。


## HTML 根本不是“编程”
html没有循环、变量、函数、逻辑，和python那种步骤化的不一样。
html是声明式的，而非命令式！
这是计算机里特别经典的一组对比。

命令式（Imperative）
代表：
C
Python
Java
JavaScript

声明式（Declarative）
代表：
HTML
CSS
SQL

---
# HTML：负责“有什么”

HTML 决定：

网页里有什么内容

比如：

标题
按钮
图片
段落
视频

这些都属于 HTML。

它像：

网页骨架

例如：

```bash
<h1>生日快乐！</h1>
<button>点击打开贺卡</button>
```

意思其实就是：

“这里有一个标题。”

“这里有一个按钮。”

---

# CSS：负责“长什么样”

CSS 决定：

网页长什么样

比如：

颜色
字体
阴影
动画
渐变
圆角
布局

这些都属于 CSS。

它像：

网页的装修与美化

例如：

```base
button {
  background: pink;
  border-radius: 999px;
}
```

意思是：

“按钮变成粉色圆角。”

---

# JavaScript：负责“会发生什么”

JavaScript 决定：

网页会发生什么

比如：

点击按钮
页面切换
弹窗
播放音乐
动画触发
游戏逻辑

这些都属于 JavaScript。

它像：

网页的大脑与动作

例如：

```base
button.onclick = () => {
  alert("生日快乐！");
}
```

意思是：

“点击按钮后，弹出一句生日快乐。”
